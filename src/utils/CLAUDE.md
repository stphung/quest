# Utils Module

Development and operational utilities: compile-time build metadata, self-update from GitHub releases, bug report generation, and a debug menu for testing.

## Files

| File | Purpose |
|------|---------|
| `mod.rs` | Module declarations, re-exports all public types from submodules |
| `build_info.rs` | Compile-time build metadata (`BUILD_COMMIT`, `BUILD_DATE`) embedded via `include!()` from `OUT_DIR/build_info.rs` generated by `build.rs` |
| `updater.rs` | Self-update system: checks GitHub releases API, compares commits, downloads platform-specific archives, extracts and replaces binary; includes `UpdateInfo`, `UpdateCheck`, `UpdateInfoStatus` types |
| `bug_report.rs` | Bug report generation: builds compact game state summary, constructs pre-filled GitHub issue URL, copies full save JSON to clipboard, opens browser; includes `BugReportData` struct |
| `debug_menu.rs` | Debug menu with 10 tabbed categories and 114+ actions for testing; `DebugMenu` struct, `DebugCategory` enum, `DebugAction` enum |

## Key Types

- **`BUILD_COMMIT`** / **`BUILD_DATE`**: Static string constants embedded at compile time. `BUILD_COMMIT` is 7 chars (short SHA) or "unknown". `BUILD_DATE` is YYYY-MM-DD format.
- **`UpdateCheck`**: Result of checking for updates -- `UpToDate`, `UpdateAvailable { current_commit, current_date, latest, changelog }`, or `CheckFailed(String)`.
- **`UpdateInfoStatus`**: Simplified result for in-game display -- `UpdateAvailable(UpdateInfo)`, `UpToDate`, or `CheckFailed(String)`.
- **`BugReportData`**: Contains a compact `summary` string (displayed in overlay) and `clipboard_content` (full save JSON in collapsible markdown blocks).
- **`DebugMenu`**: State struct with `is_open`, `selected_category`, `selected_index`. Controlled by backtick toggle, Tab/arrows for navigation, Enter to trigger.
- **`DebugCategory`**: 10 categories -- Challenges, World, Resources, Items, Deep, Zones, Character, Soulforge, Loom, Borders.

## Debug Menu

Activated with the `--debug` CLI flag. Press backtick (`) to toggle the overlay.

**10 categories with 120+ options:**

| Category | Actions |
|----------|---------|
| Challenges | Trigger all 14 challenge minigames (Chess, Morris, Gomoku, Minesweeper, Rune, Go, Flappy, JezzBall, Snake, Sigil Surge, Sudoku, Shard Fusion, Runic Lights, Vault Warden) |
| World | Trigger Dungeon, Fishing, Haven Discovery, Soulforge Discovery |

| Items | Forge Stormbreaker, Forge God Items (Asprika, Sleipnir, Megingjord) |
| Deep | Discover The Deep, Grant 10k Marks, Refresh Mission/Recruit Pools, Clear Frontier Layer, Complete Active Missions, Unlock Deep Layers (3/7/12/18/25/30) |

Debug menu actions return a status message string that is logged to the combat log with a `[DEBUG]` prefix. Discovery actions also trigger the appropriate modal overlay.

## Updater

Self-update from GitHub releases with a 15-minute check interval (+/-5 minute jitter).

**Update flow:**
1. Fetch latest release from GitHub API (`/repos/{owner}/{repo}/releases/latest`)
2. Parse release tag (`build-{full_commit_hash}`) and compare short commits
3. Skip if same commit or if local build is newer (dev build protection)
4. Fetch changelog between commits via GitHub compare API
5. Download platform-specific archive (tar.gz for Linux/macOS, zip for Windows)
6. Backup saves to `~/.quest/backups/{timestamp}/`
7. Extract archive and replace current binary
8. On macOS: ad-hoc codesign to prevent Gatekeeper blocking

**Platform assets:** `quest-x86_64-unknown-linux-gnu.tar.gz`, `quest-x86_64-apple-darwin.tar.gz`, `quest-aarch64-apple-darwin.tar.gz`, `quest-x86_64-pc-windows-msvc.zip`

## Bug Report

Generates a compact game state snapshot and opens a pre-filled GitHub issue.

**Summary fields:** Build info, character (name/level/prestige), zone, equipment rarities, fishing rank/catches, Haven/Soulforge status, achievement percentage, total kills, play time.

**Clipboard content:** Full JSON save data for character, Haven, enhancement, and achievements wrapped in collapsible `<details>` markdown blocks.

**Platform helpers:** `open_browser()` (macOS: `open`, Linux: `xdg-open`/`wslview`, Windows: `cmd /C start`), `copy_to_clipboard()` (macOS: `pbcopy`, Linux: `xclip`/`clip.exe`, Windows: `clip`).

## Integration Points

- **build_info.rs**: Referenced by `updater.rs`, `bug_report.rs`, `main.rs` (window title, splash screen)
- **updater.rs**: Called from `main_helpers/update.rs` for background update checks; also provides `run_update_command()` for CLI `quest update`
- **bug_report.rs**: Called from `input/mod.rs` (! hotkey) for overlay generation and browser launch
- **debug_menu.rs**: State managed by `main.rs`; input handled in `input/mod.rs`; rendered by `ui/debug_menu_scene.rs`
